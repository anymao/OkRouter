# 从注解到跳转：OkRouter 入门教程

本教程会完成一次可运行的 Android 路由：声明页面、启用编译期路由表、初始化并发起跳转。完成后，你将知道路由为什么不需要在运行时扫描注解。

## 你需要准备

- Android application 模块，AGP 8.13.0、JDK 17。
- 业务模块能够依赖 `com.anymore:okrouter`；应用模块能够应用 OkRouter Gradle 插件。
- URI 约定。下面示例使用 `okrouter://android/...`。

## 第 1 步：声明目标页面

在需要跳转的 `Activity` 上标注 `@Router`。`scheme`、`host` 与 `path` 共同构成路由规则；`desc` 会进入生成的路由文档，也会出现在 `resolve` 的结果中。

```kotlin
@Router(
    scheme = "okrouter",
    host = "android",
    path = "/profile",
    desc = "用户资料页"
)
class ProfileActivity : AppCompatActivity()
```

## 第 2 步：在应用模块启用生成插件

插件必须应用在 application 模块。它在每个变体的 Java 编译之后扫描 `@Router` 与 `@Interceptor`，生成 `OkRouterLoader`，并把生成源码编译回该变体的 classes 输出。

```groovy
import com.anymore.okrouter.OkRouterTransformPlugin

apply plugin: OkRouterTransformPlugin

okRouter {
    createOkRouterDoc = true
    okRouterDocFile = project.file("路由文档.md").canonicalPath
}
```

构建后可以确认生成任务存在：

```bash
./gradlew :app:tasks --all | rg 'okRouter(Register|Compile)'
```

## 第 3 步：在 `Application` 初始化

`OkRouter.init` 会调用生成的 `OkRouterLoader.load()`，将稳定路由、正则路由和拦截器注册到运行时仓储。通常在 `Application.onCreate` 中只调用一次。

```kotlin
class App : Application() {
    override fun onCreate() {
        super.onCreate()
        OkRouter.init(this)
    }
}
```

不传 `Context` 调用 `start()` 前必须完成初始化；否则会抛出 `IllegalStateException`。如果手头已有 `Activity` 或其他 `Context`，可把它显式传给 `start(context)`。

## 第 4 步：构建请求并跳转

`build` 始终保留。它返回 `RouterRequest.Builder`，可附加参数、headers、返回结果 launcher 与路由类型提示。

```kotlin
val response = OkRouter.build("okrouter://android/profile?id=42")
    .putString("entry", "home")
    .header("trace-id", "trace-42")
    .start(this)

if (response.routerResult == RouterResult.Ok) {
    // Activity 已启动；View 或 Fragment 类型时可从 response.target 取得实例。
}
```

URI 的 query 会解析进 `request.extras`：单值为 `String`，重复参数为 `ArrayList<String>`。`extras` 中还会保存内部键 `Extend.OKROUTER_RAW_URI`，用于记录原始 URI。

## 第 5 步：先预检，再决定是否跳转

`resolve` 不会初始化应用、创建目标、执行拦截器或写入正则路由缓存，适用于导航预检、埋点与调试面板。

```kotlin
when (val match = OkRouter.resolve("okrouter://android/profile?id=42")) {
    is RouterMatch.Found -> {
        println("将跳转到：${match.destination.description}")
        OkRouter.build(match.uri).start(this)
    }
    RouterMatch.NotFound -> showMissingRoute()
    is RouterMatch.Invalid -> showInvalidUri(match.reason)
}
```

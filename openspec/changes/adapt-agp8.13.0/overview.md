## 架构变更对比

### 变更前：Transform API

```
┌─────────────────────────────────────────────────────────────────┐
│              AGP 7.4.0 架构                          │
├─────────────────────────────────────────────────────────────────┤
│                                                           │
│  ┌────────────────────────────────────────────┐              │
│  │  OkRouterTransformPlugin              │              │
│  │                                    │              │
│  │  apply(project) {                   │              │
│  │      android.registerTransform(        │              │
│  │          OkRouterTransform             │              │
│  │      )                             │              │
│  │  }                                  │              │
│  └────────────────┬───────────────────────┘              │
│                 ▼                                    │
│  ┌────────────────────────────────────────────┐              │
│  │  OkRouterTransform (extends Transform)│              │
│  │                                        │          │
│  │  transform(invocation) {            │              │
│  │      // 1. 收集 class 文件         │              │
│  │      // 2. 调用扫描逻辑          │              │
│  │      // 3. 生成 .class 文件       │              │
│  │  }                                   │              │

│                 ▼                                    │
│  ┌────────────────────────────────────────────┐              │
│  │  AbsOkRouterAction                 │              │

│                                                           │
└─────────────────────────────────────────────────────────────────┘
```

## 任务执行流程

```
┌─────────────────────────────────────────────────────────────────┐
│           构建流程和任务依赖                             │
├─────────────────────────────────────────────────────────────────┤
│                                                           │
│  完整构建：                                               │
│                                                           │
│  1. 清理阶段                                             │
│     └─ clean                                              │
│                                                           │
│  2. Java 编译阶段                                         │
│     └─ JavaCompile (应用代码）                              │
│              ↓                                             │
│  3. OkRouter 注册阶段                                      │
│     └─ OkRouterRegisterTask (新）                            │
│        └─ 扫描注类                                        │
│        └─ 生成 OkRouterLoader.java                           │
│              ↓                                             │
│  4. OkRouter 编译阶段                                     │
│     └─ OkRouterCompileTask (新）                             │
│        └─ 编译 OkRouterLoader.java → .class                  │
│              ↓                                             │
│  5. Dex 构建                                           │
│     └─ DexBuilder                                            │
│                                                           │
│  增量构建（无变更）：                                     │
│                                                           │
│     JavaCompile: UP-TO-DATE                                 │
│     OkRouterRegisterTask: UP-TO-DATE                        │
│     OkRouterCompileTask: UP-TO-DATE                          │
│     DexBuilder: UP-TO-DATE                                  │
│                                                           │
│  增量构建（路由注解变更）：                               │
│                                                           │
│     JavaCompile: (可选）                                     │
│     OkRouterRegisterTask: ✅ 执行                              │
│     OkRouterCompileTask: ✅ 执行                               │
│     DexBuilder: ✅ 执行                                      │
│                                                           │
└─────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────┐
│          AsmClassVisitorFactory vs 任务依赖管理              │
├─────────────────────────────────────────────────────────────────┤
│                                                           │
│  指标               │  AsmClassVisitorFactory  │  任务依赖管理  │
│  ─────────────────┼──────────────────────────┼───────────────│
│  学习成本            │  高                   │  低         │
│  API 复杂度         │  高                   │  中         │
│  实现工作量          │  大                   │  中         │
│  代码复用率          │  低 (需重写)           │  高 (100%)  │
│  调试难度            │  高                   │  中         │
│  增量编译支持        │  内置                  │  内置       │
│  社区支持            │  文档较少               │  有成功案例  │
│  风险评估            │  高                   │  低         │
│                                                           │
│  ✅ 选择：任务依赖管理                                    │
│                                                           │
└─────────────────────────────────────────────────────────────────┘
```
